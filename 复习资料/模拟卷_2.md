## 二、编程题（共 20 分）

### 7. 全连接网络维度填空（10 分）

**题目描述：**某同学要用全连接网络完成 28×28 灰度图像的 10 分类。输入张量形状为 `[batch_size, 1, 28, 28]`。请补全模型：

```python
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear((1), 128)
        self.fc2 = nn.Linear(128, (2))

    def forward(self, x):
        x = torch.flatten(x, 1)
        x = F.relu(self.fc1(x))
        return self.fc2(x)
```

**请回答以下问题：**

1. `(1)` 和 `(2)` 分别应填什么？
2. `torch.flatten(x, 1)` 中的 `1` 表示什么？为什么不能写成 `torch.flatten(x)`？
3. 若使用 `nn.CrossEntropyLoss()`，`forward` 最后一行是否应再加 `softmax`？说明原因。

**答题要求：**建议作答时长 10 分钟。

### 8. 文本分类推理模式改错（10 分）

**题目描述：**以下代码使用含 Dropout 的文本分类模型进行单条文本推理：

```python
def predict(text):
    tokens = tokenizer(text, return_tensors="pt")
    outputs = model(**tokens)
    probs = torch.softmax(outputs.logits, dim=-1)
    return probs.argmax(dim=-1).item()
```

**请回答以下问题：**

1. 若函数在部署服务中被反复调用，上述代码遗漏了哪两项常见推理设置？
2. 请给出修改后的代码。
3. 为什么未切换评估模式可能导致带 Dropout 的模型对相同文本输出不稳定？

**答题要求：**建议作答时长 15 分钟。
