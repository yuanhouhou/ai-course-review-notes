## 一、简答题

### 1. 人工智能的发展与人机协同

#### 完整题目

请说明 AI 发展呈现波浪式特征的原因；再结合 AI 时代所需能力，说明人应如何与 AI 协同完成学习或工作任务。

#### 参考回答

1. AI 的发展受算法、算力、数据和产业需求共同影响。某一时期出现新方法时，能力和投入会快速提升；但若计算资源不足、数据规模有限，或实际效果无法达到宣传预期，投资和关注度会下降，形成低谷。
2. 波浪式发展说明单一技术突破不足以保证持续成功，必须把技术能力、可用数据和真实场景结合起来。
3. 人机协同时，应先通过精准提问明确任务目标、背景、约束和输出格式；再用思辨创新核验事实、发现 AI 输出的漏洞并形成自己的判断；最后由人组织任务分工、决定是否采纳结果并承担责任。例如写调研报告时，AI 可协助检索和梳理，人应核对来源、重组论证并决定最终结论。

### 2. 神经元、激活函数与深度网络

#### 完整题目

请说明一个人工神经元的基本计算过程，并解释激活函数的作用。进一步比较神经网络、FCNN 和 DNN 的关系。

#### 参考回答

1. 神经元先将输入 $x_i$ 与权重 $w_i$ 相乘并求和，加入偏置 $b$，得到 $z=\sum_i w_ix_i+b$；再经过激活函数得到输出 $y=f(z)$。权重表示不同输入的影响强弱，训练会不断调整权重和偏置。
2. 激活函数引入非线性。若每层都只是线性运算，多层线性变换可合并为一次线性变换，无法表示复杂的输入—输出关系。Sigmoid、tanh、ReLU 都是常见激活函数。
3. 神经网络是由相互连接神经元组成的广义计算模型；FCNN 是相邻两层神经元全部连接的一种具体结构；DNN 是具有多个隐藏层的深层神经网络。DNN 不只限于 FCNN，也可以包括 CNN、Transformer 等结构。

### 3. 训练、验证、测试与过拟合

#### 完整题目

训练损失持续下降、验证损失先降后升说明什么？请说明三类数据集用途及早停原理。

#### 参考回答

1. 该现象通常表示模型开始过拟合：它在训练集上继续记忆样本甚至噪声，因此训练损失下降；但对未见数据的泛化性能变差，所以验证损失上升。
2. 训练集参与前向计算、反向传播和参数更新；验证集不更新参数，用于选择模型、超参数和监控过拟合；测试集也不更新参数，且应在方案确定后用于最终泛化评估。
3. 早停是在验证损失连续若干轮不再改善时停止训练，并保留验证损失最低时的模型参数。它可以避免继续训练导致的过拟合和无效计算。
4. 若反复查看测试集后据此改模型或调参，测试集实际上参与了模型选择，测试结果会偏乐观，不能再代表真正未知数据。

### 4. NLP 的歧义与中文分词

#### 完整题目

为什么 NLP 不能只按字面逐词处理？请比较最短路径和 N-gram 中文分词思路。

#### 参考回答

1. 自然语言存在歧义，同一词语在不同上下文中含义可能不同；语言理解还依赖常识、说话意图和领域背景。例如相同的“打不过”在足球和乒乓球语境中可以有不同理解。因此只逐字匹配不能保证得到正确语义。
2. 最短路径方法通常依据词典构建候选词图，把不同切分方式表示为不同路径，并为词或路径赋予代价，最后选择总代价最小的路径。它体现规则、词典和优化算法的思路，结构较可解释。
3. N-gram 方法从语料中估计词序列概率，使用前面有限个词近似当前词的条件概率，再选择概率较高的切分序列。它体现统计学习思想，但受窗口长度与数据稀疏影响。

### 5. 语言模型、预训练与提示词

#### 完整题目

请解释“预测下一个 Token”，说明 N-gram 长上下文局限，并说明预训练、微调、提示词的作用。

#### 参考回答

1. 语言模型将一段文本视为序列，估计在已有上下文条件下下一个 Token 出现的概率，并选择或采样可能的后续 Token。Token 是模型处理单位，可能是字、词或子词片段。
2. N-gram 只保留前面 N-1 个单位作为上下文，难以表达更远距离的依赖；若增大 N，可能的组合数会迅速增长，需要更多参数和语料来可靠估计，容易出现数据稀疏问题。
3. 预训练让模型在大规模通用语料上学习语言规律和通用表示；微调在特定任务或领域数据上调整模型，使其更适配目标；提示词通过任务说明、背景、约束和示例引导模型完成当前任务，常用于无需或少量训练的使用场景。

### 6. 从 Copilot 到 Agent 的风险治理

#### 完整题目

请比较 Copilot 与 Agent，并为论文资料整理 Agent 设计工作流，分析风险及防护。

#### 参考回答

1. Copilot 通常由人主导，主要提供建议、草稿或局部自动化；Agent 围绕目标自主分解任务、规划步骤、调用工具并根据中间结果继续执行，因此对外部环境的影响更大。
2. 资料整理 Agent 可先读取用户明确授权的目录和任务要求；再检索指定数据库或用户提供的文献；提取题目、摘要、方法和结论；生成带来源链接的提纲；把草稿写入指定新文件，最后请用户审阅和确认。
3. 幻觉会造成虚构引用或错误综述，应要求来源、逐条核验重要结论；读取文件可能泄露隐私，应采用最小权限、限定目录和数据脱敏；提示注入可能诱导工具越权，应将外部文本视为不可信输入；写入操作应限定路径、保留版本和日志，并对覆盖或发布动作请求确认。

## 二、编程题

### 7. 神经网络训练步骤排序与补全

#### 完整题目

补全二分类网络的训练代码，并解释清零梯度和 logits 的作用。

#### 参考回答

1. 两处应填：

```python
loss.backward()
optimizer.step()
```

`loss.backward()` 通过反向传播计算模型参数的梯度；`optimizer.step()` 根据梯度更新参数。

2. PyTorch 默认会累积参数梯度。若不在每个 batch 前调用 `optimizer.zero_grad()`，当前 batch 的梯度会叠加到前一个 batch，通常会导致更新方向和大小不符合当前训练目标。

3. `BCEWithLogitsLoss` 已将 Sigmoid 与二元交叉熵组合为数值更稳定的计算，因此应传入未经过 Sigmoid 的原始输出 logits。若在模型中先手动 Sigmoid 再传入该损失，会重复处理并可能影响训练。

### 8. 验证集早停逻辑改错

#### 完整题目

改正验证损失保存与早停逻辑，并说明为什么加载最优模型测试。

#### 参考回答

1. 原代码把 `val_loss > best_val_loss` 当作“更好”，方向相反；它还在第一次未改善时直接停止，无法容忍正常波动。
2. 可修改为：

```python
best_val_loss = float("inf")
patience = 3
bad_epochs = 0

for epoch in range(epochs):
    train_one_epoch(model, train_loader, optimizer)
    val_loss = evaluate(model, val_loader)

    if val_loss < best_val_loss:
        best_val_loss = val_loss
        bad_epochs = 0
        torch.save(model.state_dict(), "best.pt")
    else:
        bad_epochs += 1
        if bad_epochs >= patience:
            break
```

3. 最后一个 epoch 的模型可能已开始过拟合，验证表现不一定最好。加载保存的最优模型，才能使最终测试结果对应验证阶段选择出的泛化性能较好的参数。
