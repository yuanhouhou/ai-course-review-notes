## 一、简答题

### 1. 人工智能的定义、应用与局限

#### 完整题目

**题目描述：**请简要定义人工智能（AI），并列举两个你在日常生活中接触过的人工智能应用（如语音助手、推荐系统、人脸识别等）。针对其中一个应用，说明它目前存在的主要局限性（如隐私、误判、偏见等）。

**建议从以下角度组织答案：**

1. 用自己的话说明人工智能主要能处理什么问题，表现出哪些能力；
2. 分别列举两个日常生活中的应用，并简要说明它们分别能帮助人们完成什么事情；
3. 从其中一个应用出发，分析至少一项现实局限，以及该局限可能造成的影响。

**答题要求：**建议作答字数 200～300 字，建议作答时长 10 分钟。

#### 参考回答

1. 人工智能是让计算机利用数据、算法和模型完成感知、学习、推理、预测或决策等任务的技术。它能从大量信息中发现规律，例如识别图像和语音、理解文本、预测偏好，并在明确目标下给出建议或执行特定操作。
2. 手机语音助手可把语音转换为指令，帮助用户设置闹钟、查询天气或拨打电话；电商、短视频平台的推荐系统可根据浏览、点击和购买记录推送商品或内容，降低用户筛选信息的成本。
3. 以推荐系统为例，它需要收集用户行为数据，保护不当可能造成隐私泄露；同时算法可能持续推送相似内容，强化既有偏好，形成“信息茧房”，减少用户接触不同信息和观点的机会。

### 2. 图灵测试及其局限

#### 完整题目

**题目描述：**用一段话解释什么是图灵测试，并简要说明它为何不能完全等同于智能的判定标准。

**建议从以下角度组织答案：**

1. 说明测试中有哪些参与者，以及参与者之间通过什么方式交流；说明测试过程和判断机器是否通过测试的基本依据；
2. 从“外在表现是否等于真正理解或具备智能”的角度，分析图灵测试存在的局限。

**答题要求：**建议作答字数 200 字，建议作答时长 10 分钟。

#### 参考回答

1. 图灵测试由评判者、人和机器三方参与。评判者在不知道对方身份的情况下，通常通过文字与一名人和一台机器交流、提问，再依据回复判断哪一方是机器；若机器在限定时间内使评判者不能可靠地区分其与人，就可认为它通过了测试。
2. 该测试衡量的是系统在语言交流中的外在拟人表现，但外在表现不必然等于真正理解。机器可能借助语言模式生成自然回答，却不一定具有常识、因果理解、情感体验或自主目标；反过来，擅长感知、规划和控制的系统也未必能像人一样闲聊。因此它只能评价某一类交互能力，不能成为判定智能的唯一标准。

### 3. 主流神经网络与 Transformer 的核心机制

#### 完整题目

**题目描述：**请简述主流神经网络模型的主要类型，并说明构建 Transformer 及现代语言模型所依赖的核心基础组件或机制。

**建议从以下角度组织答案：**

1. 列举若干主流神经网络类型，可以同时写出中文名称和英文简称；
2. 说明 Transformer 在处理一段文字或序列时，如何建立不同位置内容之间的联系；
3. 从“文字如何表示”“顺序如何体现”“信息如何反复加工”等角度，说明现代语言模型需要的基础组成部分或机制。

**答题要求：**建议作答字数 200～300 字，建议作答时长 10 分钟。

#### 参考回答

1. 主流神经网络包括前馈神经网络（FNN/MLP）、卷积神经网络（CNN）、循环神经网络（RNN）及其 LSTM、GRU 变体，以及 Transformer。CNN 常用于图像局部特征提取；RNN 类模型按顺序处理序列；Transformer 是当前大语言模型的重要基础结构。
2. Transformer 使用自注意力（Self-Attention）机制：序列中每个位置都会计算与其他位置的相关性，并按相关性加权汇聚信息，因此能直接建立远距离词语之间的联系。
3. 现代语言模型先把文字切分为 token，用词嵌入把 token 表示为向量；再加入位置编码以保留词序；随后堆叠多层注意力和前馈网络，对上下文表示反复加工。训练时常通过预测下一个 token 学习语言规律，生成时逐个输出 token。

### 4. AI Agent 的含义、区别、应用与风险

#### 完整题目

**题目描述：**当前人工智能正在从“回答问题的模型”逐渐发展到能够调用工具、规划步骤并执行任务的 AI Agent。请解释什么是 AI Agent，并说明它与普通聊天机器人的主要区别。请举一个实际应用案例，并分析使用 Agent 时可能面临的风险。

**建议从以下角度组织答案：**

1. 说明 AI Agent 如何围绕一个目标获取信息、制定步骤、使用工具并根据结果继续调整；
2. 从“是否只能回答问题”“能否执行外部操作”“能否完成多步骤任务”等角度，将其与普通聊天机器人进行比较；
3. 给出一个完整应用案例，说明其任务目标、主要执行步骤、可能使用的工具以及最终结果；
4. 分析至少一项可能风险，并说明该风险可能产生的后果。

**答题要求：**建议作答字数 200～300 字，建议作答时长 15 分钟。

#### 参考回答

1. AI Agent 是以目标为导向的智能体。它会理解目标和约束，检索信息、分解子任务、制定计划、调用搜索或软件工具，并根据中间结果修正下一步行动。
2. 普通聊天机器人主要生成对用户问题的文本回答，通常不直接改变外部环境；Agent 不仅能回答，还可调用 API、浏览器、数据库或办公工具，并连续完成多步骤任务。
3. 例如旅行规划 Agent 的目标是生成并执行出行方案：它读取日期、预算和偏好，搜索交通与酒店、比较价格、生成行程；得到用户确认后，可调用预订接口完成下单，最后输出订单和日程。
4. 若信息过期、理解错误或受到恶意提示影响，Agent 可能做出错误操作；当它拥有支付或个人数据权限时，可能造成误订、资金损失或隐私泄露。因此应限制权限，并对付款、删除等关键操作设置人工确认和日志审计。

### 5. 多模态 AI 的含义、应用与挑战

#### 完整题目

**题目描述：**请简要解释多模态 AI 的含义，并举例说明其在现实中的一个应用场景。相比于单一模态 AI，多模态 AI 面临的主要挑战是什么？

**建议从以下角度组织答案：**

1. 说明“多模态”中的“多”指哪些不同形式的信息，以及这些信息如何共同参与任务；
2. 选择一个应用案例，具体说明其中至少两种信息形式分别发挥了什么作用；
3. 从不同信息之间如何对应和配合、数据获取、结果质量、计算成本等角度，分析至少两项技术挑战。

**答题要求：**建议作答字数 200～300 字，建议作答时长 15 分钟。

#### 参考回答

1. 多模态 AI 中的“多”是指文本、图像、语音、视频、传感器等不同形式的信息。系统将它们对齐、融合和推理，以获得更完整的场景理解和用户意图。
2. 例如智能售后客服中，用户上传损坏商品的照片并用语音说明问题。图像用于识别商品部件、损坏位置和外观状态；语音转写后的文本用于理解用户希望退换、维修还是咨询；系统再结合说明书给出步骤或创建工单。
3. 不同模态存在时间和语义对齐难题，例如一句语音对应视频的哪个片段；高质量图文、音视频配对数据也难采集和标注。此外，模态可能缺失、含噪或彼此冲突，影响结果质量；多模态模型参数更多，训练和推理成本、延迟也更高。

### 6. 大语言模型幻觉

#### 完整题目

**题目描述：**什么是大语言模型中的“幻觉”（Hallucination）现象？请分析其可能产生的原因（至少两点），并简述一种目前常用的缓解策略。

**建议从以下角度组织答案：**

1. 说明“幻觉”生成的内容在表面上有什么特点，以及它与真实事实之间可能存在什么问题；
2. 从模型生成内容的方式、学习数据、用户提供的信息、知识时效等不同角度，分析至少两种可能原因；
3. 提出一种缓解方法，并说明该方法为什么能够减少错误，而不是只写出方法名称。

**答题要求：**建议作答字数 200～300 字，建议作答时长 15 分钟。

#### 参考回答

1. 大语言模型幻觉是指模型给出的内容语句流畅、形式上很像正确答案，却与事实、给定材料或逻辑约束不一致，例如虚构论文、数据、人物经历或网址。
2. 模型的基本目标是根据上下文预测下一个 token，而不是逐条核验事实；信息不足时，它可能生成统计上“像答案”的补全内容。训练数据也可能含噪声、矛盾或覆盖不足，模型知识可能过时；当用户问题含糊、上下文缺失或超出模型知识范围时，模型仍可能自信作答。
3. 常用策略是检索增强生成（RAG）：系统先从可信知识库检索材料，再把检索结果连同问题交给模型回答，并要求引用来源。回答会受到可核查证据约束，能减少凭空编造；但关键结论仍应进行引用核验或人工复核。

### 7. 神经网络测试模式设置（Dropout 改错）

#### 完整题目

**改错题：神经网络测试模式设置**

**题目描述：**某同学训练了一个用于图像分类的神经网络。为了减少过拟合，模型中使用了 Dropout 层。

模型定义如下：

```python
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(100, 64)
        self.dropout = nn.Dropout(p=0.5)
        self.fc2 = nn.Linear(64, 10)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        return x
```

训练完成后，同学使用下面的代码在测试集上进行预测：

```python
correct = 0
total = 0
with torch.no_grad():
    for x, y in test_loader:
        outputs = model(x)
        _, predicted = torch.max(outputs, 1)
        total += y.size(0)
        correct += (predicted == y).sum().item()

accuracy = correct / total
print("Test accuracy:", accuracy)
```

Dropout 在训练阶段会随机关闭一部分神经元；在测试阶段，应关闭这种随机行为；`model.eval()` 可以将模型切换到评估模式。

**请回答以下问题：**

1. 上述测试代码存在什么问题？
   - 建议从模型当前所处的运行状态分析；
   - 说明该状态下 Dropout 的随机行为为什么会导致两次输出不同。
2. 请修改代码，使模型能够按照正确的方式进行测试。
3. 测试完成后，如果还需要继续训练模型，应执行什么操作？
   - 说明完成测试后，如还需要继续训练，应该进行什么状态恢复操作。

**答题要求：**建议作答时长 20 分钟。

#### 参考回答

1. 测试前没有调用 `model.eval()`，模型默认仍处于训练模式。此时 `Dropout` 每次前向传播都会随机将部分神经元输出置零，同一输入的有效网络结构可能不同，因此两次预测结果或准确率会波动。`torch.no_grad()` 只是不记录梯度，不会关闭 Dropout 的随机行为。
2. 正确测试代码如下：

```python
model.eval()  # 切换到评估模式，关闭 Dropout 的随机失活

correct = 0
total = 0
with torch.no_grad():
    for x, y in test_loader:
        outputs = model(x)
        _, predicted = torch.max(outputs, 1)
        total += y.size(0)
        correct += (predicted == y).sum().item()

accuracy = correct / total
print("Test accuracy:", accuracy)
```

3. 若测试后还要继续训练，应执行 `model.train()`，把模型恢复为训练模式，使 Dropout 重新按训练规则随机失活：

```python
model.train()
```

### 8. 构建简单 CNN 图像分类模型

#### 完整题目

**编程理解题：构建简单 CNN 图像分类模型**

**题目描述：**某研究小组希望使用卷积神经网络 CNN 对图片进行分类。输入图片大小为 `3×32×32`：其中 `3` 表示 RGB 三个颜色通道，`32×32` 表示图片尺寸，共需要识别 10 个类别。

研究人员设计了如下网络：

```text
输入：3×32×32
↓ Conv1：3 通道 → 8 通道
↓ ReLU
↓ 2×2 MaxPool
↓ Conv2：8 通道 → 16 通道
↓ ReLU
↓ 2×2 MaxPool
↓ Flatten
↓ Linear
↓ 输出 10 个类别
```

为帮助完成程序，现给出第一个卷积层的完整写法：

```python
self.conv1 = nn.Conv2d(
    in_channels=3,
    out_channels=8,
    kernel_size=3,
    padding=1
)
```

请按照第一层补全第二层：

```python
self.conv2 = nn.Conv2d(
    in_channels=(1),
    out_channels=(2),
    kernel_size=3,
    padding=1
)

self.pool = nn.MaxPool2d(2)

# 两次池化后，将特征展平并输入全连接层
self.fc = nn.Linear((3), 10)

def forward(self, x):
    # Conv1 → ReLU → Pool
    x = self.pool(F.relu(self.conv1(x)))

    # Conv2 → ReLU → Pool
    x = self.pool(F.relu((4)(x)))

    x = torch.flatten(x, 1)
    x = self.fc(x)
    return x
```

**答题要求：**请在四处空白处填入代码，建议作答时长 25 分钟。

#### 参考回答

1. `(1)` 为 `8`，因为第二层卷积的输入通道必须等于第一层的输出通道。
2. `(2)` 为 `16`，因为网络结构指定第二层输出 16 通道。
3. `(3)` 为 `16 * 8 * 8`（或 `1024`）。两层卷积均使用 `kernel_size=3, padding=1`，空间尺寸不变；两次池化使 `32×32 → 16×16 → 8×8`，第二层有 16 个通道，所以展平维度为 `16×8×8=1024`。
4. `(4)` 为 `self.conv2`，即在第二次卷积阶段调用第二层卷积。

填空后的完整代码：

```python
self.conv2 = nn.Conv2d(
    in_channels=8,
    out_channels=16,
    kernel_size=3,
    padding=1
)

self.pool = nn.MaxPool2d(2)
self.fc = nn.Linear(16 * 8 * 8, 10)

def forward(self, x):
    x = self.pool(F.relu(self.conv1(x)))
    x = self.pool(F.relu(self.conv2(x)))
    x = torch.flatten(x, 1)
    x = self.fc(x)
    return x
```
