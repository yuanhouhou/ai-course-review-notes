## 一、基础简答题

### 1. 泛化、交叉验证与模型选择

欠拟合是模型能力或训练不足，训练集和验证集都表现较差；拟合较好时两者均较好；过拟合时训练集持续改善而验证集变差，说明对未知数据泛化不足。交叉验证将有限数据轮流划为训练部分和验证部分，能更稳定地估计不同超参数或模型的表现，减少一次随机划分带来的偶然性。交叉验证仍服务于模型选择；最终测试集必须独立保留，在方案确定后进行一次客观泛化评估，不能因交叉验证结果而反复调测试集。

### 2. 强化学习问题建模

状态可包含机器人坐标、障碍物与目标位置；动作可为上下左右移动或转向；奖励可对到达目标给较大正奖励、碰撞给负奖励、每步给小代价以鼓励短路径。策略规定每个状态选择动作的方式，价值函数估计状态或状态—动作在未来可获得的累计回报。探索是尝试不确定动作以获得信息，利用是选择当前估计最优动作，两者需平衡。奖励若只鼓励速度，机器人可能采取危险捷径；应把安全约束、碰撞惩罚和真实环境验证纳入设计。

### 3. 注意力机制与 Transformer

Query 表示当前位置要寻找的信息，Key 表示各位置可被匹配的索引，Value 是被加权汇聚的内容。Query 与各 Key 的相似度形成分数，经 softmax 归一化为注意力权重，再对 Value 加权求和。因此一个 token 可直接关注序列中任意位置，捕捉指代、远距离依赖等关系。N-gram 仅用固定数量的前文，窗口外信息无法直接进入条件概率；自注意力不是固定窗口，能动态分配不同位置的权重，但较长序列通常带来更高计算和存储代价。

## 二、前沿简答题

### 4. 具身智能的感知、决策与执行

图像或文本问答只评价表征和生成，搬运机器人还必须在真实环境中安全行动。闭环为：相机、力觉等感知环境；融合观测估计物体和自身状态；根据任务规划路径与抓取动作；控制执行器执行；再用新观测检查是否偏差并修正或停止。安全指标可包括碰撞率/急停率、任务成功率与误抓率、动作完成时延、异常情形下的安全停止成功率和人工接管次数。系统应在仿真与受控环境逐步验证，并保留可恢复、可人工接管的机制。

### 5. RAG 与大模型幻觉治理

模型参数中的知识可能过时且难以追溯；RAG 在回答前从版本化、授权的校规和通知库检索相关片段，使内容可更新并可展示依据。流程可为：维护带发布时间和权限标签的知识库→根据问题检索和重排序→只基于足够相关的证据生成→在界面展示来源、适用时间和置信提示→证据不足时拒答或转人工→收集纠错并更新索引。应评测检索召回、引用正确性、回答事实性、拒答正确率、时延和用户反馈；RAG 降低幻觉但不能代替来源质量控制和人工核验。

### 6. AI 安全、伦理与社会责任

数据投毒在训练数据阶段混入恶意样本；后门通常在训练或供应链中植入触发条件，平时正常、触发时异常；对抗样本多在推理阶段以细微扰动诱导误判；算法偏见可能来自数据代表性不足、目标设定或部署反馈，造成群体间不公平。措施包括：数据授权、脱敏、质量审查和投毒检测；依赖与模型来源审计、后门与鲁棒性测试；按身份最小权限访问并隔离工具；内容安全过滤、提示注入防护和高风险人工确认；记录必要审计日志、提供申诉纠错和透明说明；遵守法律、学校制度并引入持续监督。技术防护与伦理治理必须共同进行。

## 三、编程题

### 7. 含 Dropout 模型的推理改错

原代码处于训练模式，Dropout 会随机置零部分激活，故同一文本多次前向计算可能波动；同时未关闭梯度记录，增加不必要的显存和计算。可修改为：

```python
def predict(text):
    model.eval()
    tokens = tokenizer(text, return_tensors="pt")
    with torch.no_grad():
        outputs = model(**tokens)
        return torch.softmax(outputs.logits, dim=-1).argmax(dim=-1).item()
```

若模型与输入不在同一设备，还应将 tokens 移至模型所在设备。`eval()` 也会使 BatchNorm 使用已学习的统计量；推理完成后若继续训练，应调用 `model.train()`。

### 8. 缩放点积注意力理解

`scores` 是每个 Query 与各 Key 的匹配分数；`weights` 是经 softmax 后对各 Key/Value 的归一化关注权重；`output` 是对 Value 的加权汇聚结果。维度较大时点积数值的方差会增大，除以 `sqrt(d_k)` 可避免 softmax 过早饱和，使梯度和权重分布更稳定。最后一维通常对应“当前 Query 可关注的所有 Key 位置”，在该维度做 softmax 才能使每个 Query 的权重和为 1。
