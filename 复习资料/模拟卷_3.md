## 三、编程改错题（10 分）

### 7. CNN 分类器维度与训练模式改错

**题目描述：**输入图像形状为 `[batch_size, 3, 32, 32]`。以下模型包含两次 `2×2` 最大池化，请找出至少两处错误并给出修改后的关键代码。

```python
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 8, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(8, 16, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc = nn.Linear(16 * 16 * 16, 10)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = torch.flatten(x)
        return F.softmax(self.fc(x), dim=1)
```

**请回答：**`fc` 的输入维度应为何值？`flatten` 应如何写？若训练使用 `nn.CrossEntropyLoss()`，最后一行应如何修改？

## 四、编程理解题（10 分）

### 8. 训练与验证循环理解

```python
for epoch in range(epochs):
    model.train()
    for x, y in train_loader:
        optimizer.zero_grad()
        logits = model(x)
        loss = criterion(logits, y)
        loss.backward()
        optimizer.step()

    model.eval()
    with torch.no_grad():
        val_loss = sum(criterion(model(x), y).item() for x, y in val_loader)
```

**请回答：**

1. `model.train()`、`model.eval()` 分别影响哪些典型层？
2. `torch.no_grad()` 的作用是什么？
3. 为什么 `val_loss` 只能用于选模型、调参或早停，不能直接用来更新权重？
